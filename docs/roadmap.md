# 🗺 Roadmap

[← Back to Documentation Index](README.md)

## Current Milestones
- [x] Basic Proportion Metric Evaluation (Z-Tests).
- [x] Pre-test Power Calculations for conversions.
- [x] SRM checks via Chi-Square.
- [x] Automated HTML executive reporting.

## Future Goals
- **Continuous Metrics**: Support for Welch's T-Test for Revenue per User (ARPU) evaluations.
- **Bayesian Evaluation**: Add an optional Bayesian engine for credible intervals.
- **Multiple Variants**: Expand SRM and Evaluator to handle A/B/C/n tests using ANOVA.
- **Sequential Testing**: Add support for peeking using alpha-spending functions (e.g., O'Brien-Fleming).
